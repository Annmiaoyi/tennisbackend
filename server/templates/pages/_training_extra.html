info 统计口径（可复核）
① 会话汇总（主口径） 球速类（发球 / 整体 / 正手 / 反手）与负荷类（时长 / 卡路里 / 心率 / 击球总数 / 甜区率） 全部取自 training_sessions 的会话字段，即手表对整场的统计结果 —— 没有抽样偏差，且每条训练记录都齐全。个人明细表、技术分析、排行榜三处同源， 同一学员同一指标不会出现两个数。
② 逐拍抽样（仅补齐会话表没有的维度） stroke_records 在库中是抽样存储（实测一场十几条， 而非该场全部击球）。因此它只用于会话表没有对应列的维度：击球构成占比、 切削球速、转速、落点。这些位置都标注了「逐拍抽样」并给出样本量。 不要拿样本峰值当整场峰值 —— 样本抽样会让峰值系统性偏低。
③ 不使用档案汇总字段 students 表的 sessions_count / strokes_total / serve_peak / forehand_avg 等为人工维护的展示值， 与真实记录不一致（实测：某学员 serve_peak=179，但记录中该学员发球峰值仅 166.9； sessions_count=124 而实际只有 8 场）。本页一律现算，保证任何数字都能用一条 SQL 复现。
